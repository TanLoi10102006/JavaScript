# 🚀 JavaScript Learning Repository

Repository này lưu trữ các kiến thức và bài thực hành JavaScript được xây dựng trong quá trình tự học lập trình.

## 📖 Giới thiệu

Dự án bao gồm các chủ đề JavaScript cơ bản đến hướng đối tượng nhằm giúp củng cố nền tảng lập trình và chuẩn bị cho việc học Front-end, Back-end và các framework JavaScript hiện đại.

## 📂 Nội dung

### 🔢 Array
- Khai báo mảng
- Thêm, sửa, xóa phần tử
- Duyệt mảng
- Các phương thức thông dụng

### 🔤 String
- Xử lý chuỗi
- Các hàm thao tác chuỗi
- Tìm kiếm và cắt chuỗi

### 🔁 Vòng lặp
- for
- while
- do...while
- break và continue

### ⚙️ Function
- Khai báo hàm
- Function Expression
- Arrow Function
- Tham số và giá trị trả về

### 🧠 Điều kiện
- if...else
- switch...case
- Toán tử so sánh
- Toán tử logic

### 🏛️ OOP
- Object
- Constructor Function
- Prototype
- Encapsulation
- Inheritance cơ bản

### 📝 Bài tập thực hành
- Các bài tập luyện tập theo từng chủ đề
- Các ví dụ minh họa và ứng dụng thực tế

## 🛠 Công nghệ sử dụng

- JavaScript
- HTML

## 🎯 Mục tiêu

- Xây dựng nền tảng JavaScript vững chắc.
- Rèn luyện tư duy lập trình.
- Chuẩn bị cho ReactJS, Node.js và các công nghệ Web hiện đại.

## ▶️ Cách sử dụng

Mở trực tiếp các file `.js` hoặc chạy bằng trình duyệt thông qua các file HTML tương ứng.

Ví dụ:

```javascript
node main.js
```

hoặc mở:

```text
index.html
```

trên trình duyệt.
